# 📅 Command Line Calendar

## Description

Command Line Calendar is a Java-based console application that allows users to view calendars, check dates, find weekdays, and manage personal events.

This project demonstrates Java Object-Oriented Programming concepts, date handling, and file handling.

---

## Features

- Display monthly calendar
- Display yearly calendar
- Check leap year
- Find day of the week for a given date
- Add events
- View saved events
- Store events using file handling

---

## Technologies Used

- Java
- Java Time API
- File Handling
- Object-Oriented Programming (OOP)
